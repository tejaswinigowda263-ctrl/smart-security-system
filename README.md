
# Smart Security System

This project is a Smart Security Dashboard built using React.

## Features
- Login system
- Sensor simulation (Temperature, Motion, Smoke)
- Alert system (Safe / Danger)
- Live camera simulation
- Temperature graph using Recharts
- Sidebar navigation

## How to Run
1. npm install
2. npm start

## Description
This project simulates a real-time security monitoring system with alerts and live data updates.

## Technologies Used
- React.js
- Recharts
